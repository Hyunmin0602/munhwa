# ADR 001: 앱 내 멘션 알림

- 상태: 승인됨
- 날짜: 2026-10-11

## 결정

알림은 앱 안의 알림함에서만 제공한다. 카드 댓글 멘션, 새 업무 배정, 마감 임박·초과, 회의록 공유, 가입 승인 알림을 저장한다. 마감 알림은 매일 예약 작업이 담당자의 미완료 업무를 확인하며, 작업당 마감일별 한 번만 생성한다. 이메일·푸시 전송은 포함하지 않는다.

알림은 수신자별 읽음 시각을 가진다. 사용자는 알림 유형별 수신을 끌 수 있으며, 설정이 꺼진 동안 생성되는 알림은 저장하지 않는다. 알림 목록은 `createdAt + id` 복합 커서로 페이지네이션하고 요약 필드만 반환한다.

## 권한과 정합성

댓글 API가 프로젝트 편집 권한을 검증한다. 멘션 대상은 프로젝트 구성원, 사업 소유자, Space 관리자 또는 Space 관리자 권한 구성원으로 제한하고 서버에서 다시 검증한다. 알림 조회와 읽음 변경은 수신자 ID 조건을 항상 포함한다. 읽음 변경은 `withDbWrite` 단일 시도로 실행한다.

예약 마감 작업은 `CRON_SECRET`을 통한 Bearer 인증을 요구한다. 알림의 dedupe key는 반복 실행에서 같은 마감 알림이 중복 생성되는 것을 막는다.

## 결과

댓글 본문과 멘션 대상은 별도 관계 테이블 없이 저장된 알림으로 연결한다. 알림 이동 링크는 카드·회의록 대상 경로이며, 대상 API가 권한을 다시 검증한다.
